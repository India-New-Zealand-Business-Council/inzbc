# Module — Public website

Owner: Paras · Status: planned · Platform: Wix (CMS + dynamic pages + forms).

## Purpose
Public marketing and conversion layer. Presents approved information; drives join, event
registration, and enquiries. Not the member portal (see member-portal.md) and not internal apps.

## Pages
Home · About & history · Board/executive/chapters · Sponsors & partners · Events & registration ·
News/media/approved intelligence digests · FTA Centre public overview · Sector reports & publications ·
Membership benefits & join pathway · Trade services / market-entry · Delegations · Contact ·
privacy/terms/accessibility/complaints.

## Wix building blocks
Wix CMS, dynamic pages (one layout → many report/event/board/sector pages), Wix Events, Wix Forms,
Site Search, Automations, Analytics, structured data. Velo only where standard functions fall short.

## CMS collections
News, Events Archive, Sector Reports, FTA Resources, Board Members, Team, Sponsors, Partners,
Member Directory (opt-in fields), Delegations, Case Studies, Media Coverage, Publications, Videos,
FAQs, Testimonials, Market-Entry Services.

## Forms → internal
Each submission: confirmation email + owner notification + webhook to the internal system (Bhanu's
webhook contract). Forms: join, renew, event enquiry, sponsorship, market-entry (both directions),
introduction request, delegation EOI, speaker, media, newsletter, profile update, member news, contact.

## Dependencies
Bhanu's webhook contract; Roshan's FTA service (Explainer embed); INZBC brand kit + content.

## Open decisions
Payment provider for join/renew (only if membership moves to Wix — see membership-crm.md); which
content is public vs member-only.

## Definition of done
IA + content approved; WCAG 2.2 AA; forms deliver to the right owner with spam protection;
analytics + Search Console; redirects/SEO verified; content owners trained.
