# Module — Member portal

Owner: Paras · Status: planned · Platform: Wix Members Area (login-gated).

## Purpose
Logged-in member experience: resources, renewals, and request forms. Sits on the membership
decision (see membership-crm.md) — if Member Jungle stays the system of record, the portal links to
it rather than duplicating membership.

## Member sees
Membership status + renewal · organisation/contact details · invoices/receipts · member-only
reports & FTA briefings · event recordings & presentations · delegation & trade opportunities ·
market-entry request form · introduction request form · discounts & sponsor benefits · directory
& consent preferences.

## Roles (Wix member roles)
Individual · Corporate · Strategic Partner · Sponsor · Board · Staff · Admin. Portal access is
separate from membership category and from admin authority (brief §7).

## Corporate membership
Organisation record, primary + billing contact, authorised seats, seat add/remove/transfer,
directory consent, continuity when a contact leaves.

## Dependencies
Membership platform decision (Member Jungle retain/integrate/replace); Bhanu's auth/roles; the
website shell (Paras).

## Open decisions
Single sign-on vs separate Member Jungle login (Option A/B); which resources are member-only.

## Definition of done
Login + roles gate content correctly; renewal/status visible; request forms route to the right
owner; expired/former-member access rules enforced; consent captured.
