# Module — Events & delegations

Owner: Paras · Status: planned · Public registration (Wix Events) + internal management.

## Purpose
Run INZBC events (incl. the Summit) and India–NZ delegations end to end: plan, register, manage,
follow up, and record outcomes.

## Event lifecycle
Planning template + budget · registration + invitations · VIP management · speaker info · sponsor
benefits at the event · seating · QR/attendance check-in · follow-up emails · photos/media ·
event outcome report.

## Delegations
Itinerary, participant management, meeting matching, follow-up and outcome tracking.

## Dependencies
Website + member portal (Paras); Bhanu's records/API for outcomes; sponsor benefits module for
event visibility; INZBC event calendar + past-event archive.

## Open decisions
Event platform: Wix Events vs a dedicated event tool; check-in mechanism; ticketing/payment if paid.

## Definition of done
An event can be created, registered for, checked in, followed up, and reported; sponsor benefits
recorded; delegation participants + outcomes tracked; data feeds the dashboards.
