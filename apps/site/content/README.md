# Public site content (drafts)

Draft copy for the new INZBC public pages, from `docs/page-specs.md`. Executive tone, politically
neutral, no invented facts. `[[placeholders]]` mark anything INZBC must supply or confirm.

These are content drafts, not the Wix build. They drop into Wix CMS / pages once the Wix site is
set up. Wix account access is granted at team level; programmatic build is blocked on connecting
the Wix MCP (manual build in the Wix editor can start now), and on the brand kit. See
`docs/discovery.md` OI-1. The visual look comes from `DESIGN.local.md` + INZBC's brand kit, not
from this copy.

Pages here: home, about, events, members, connect, partners, trade. The Digest and FTA Explainer
pages are separate (gated modules) and live with their own specs; `trade.md` links to the FTA
Explainer rather than duplicating it. Board/Executive Council names and bios are pulled from INZBC
at build time, never drafted here.
