# Public site content (drafts)

Draft copy for the new INZBC public pages, from `docs/page-specs.md`. Executive tone, politically
neutral, no invented facts. `[[placeholders]]` mark anything INZBC must supply or confirm.

These are content drafts, not the Wix build. They drop into the duplicate site's pages via the Wix
editor once Sunil creates it (`docs/discovery.md` OI-9). Not the live site. Wix account access is
granted at team level, so manual build can proceed as soon as the duplicate exists; only
*programmatic* build is blocked, on connecting the Wix MCP (`docs/discovery.md` OI-1). The brand
kit blocks the visual restyle, not content work. The visual look comes from `DESIGN.local.md` +
INZBC's brand kit, not from this copy.

This file stays the source of truth for page copy. When copy is changed in the Wix editor, update
the matching `.md` here in the same PR, or the two drift apart with no record of which one wins.

Pages here: home, about, events, members, connect, partners, trade. The Digest and FTA Explainer
pages are separate (gated modules) and live with their own specs; `trade.md` links to the FTA
Explainer rather than duplicating it. Board/Executive Council names and bios are pulled from INZBC
at build time, never drafted here.
